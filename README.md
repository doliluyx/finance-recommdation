# 🌿 DoriFit - AI 금융상품 맞춤 추천 서비스

> 사용자의 금융정보와 투자성향을 바탕으로 맞춤형 예금상품을 추천하고, AI 챗봇을 통해 금융상품 상담을 제공하는 웹 서비스입니다.

<br>

## 📌 프로젝트 소개

**DoriFit(도리핏)**&#xC740; 개인의 금융 상황과 투자성향을 고려하여 적합한 금융상품을 탐색할 수 있도록 지원하는 AI 기반 금융상품 추천 플랫폼입니다.

회원가입 시 입력한 나이, 직업, 연소득, 투자성향 등의 정보를 활용하여 예금상품을 추천하고, AI 금융상담 챗봇을 통해 금융상품 및 자산관리에 관한 질문에 답변합니다.

단순한 상품 나열을 넘어 사용자의 금융정보를 기반으로 개인화된 금융 경험을 제공하는 것을 목표로 합니다.

<br>

## 🛠️ 사용 기술

| 구분              | 기술                    | 활용 내용                |
| --------------- | --------------------- | -------------------- |
| Backend         | Python                | 서버 및 비즈니스 로직 구현      |
| Web Framework   | FastAPI               | 웹 서버 및 API 구현        |
| Frontend        | HTML, CSS, JavaScript | 웹 페이지 및 사용자 인터페이스 구현 |
| Template Engine | Jinja2                | 서버 데이터 기반 동적 페이지 렌더링 |
| Database        | SQLite                | 회원정보 저장 및 관리         |
| Data Processing | CSV                   | 금융상품 데이터 수집 및 처리     |
| AI              | OpenAI API            | 금융상품 상담 및 자연어 응답 생성  |
| Authentication  | SessionMiddleware     | 로그인 세션 관리            |
| Security        | hashlib, PBKDF2       | 비밀번호 해시 처리           |
| Server          | Uvicorn               | FastAPI 애플리케이션 실행    |

<br>

## ⚙️ 주요 기능

### 1. 회원가입 및 로그인

* 사용자 회원가입 및 로그인 기능
* 아이디 중복 확인 및 회원정보 관리
* 이름, 나이, 성별, 직업, 연소득 입력
* 투자성향 선택 (안정형 ~ 공격투자형)
* 프로필 이미지 업로드 및 미리보기
* 비밀번호 해시 처리 및 세션 기반 로그인 유지

### 2. 개인 맞춤형 금융상품 추천

* 회원가입 시 입력한 금융정보 활용
* 투자성향 및 개인 조건을 고려한 예금상품 추천
* CSV 기반 금융상품 데이터 로드
* 상품별 금융회사, 상품명, 기본금리, 최고금리 정보 제공
* 가입기간, 가입금액, 가입대상 등 상품 상세정보 확인
* 상품별 상세 페이지 연결

### 3. AI 금융상담 챗봇

* OpenAI API 기반 금융상담 기능
* 자연어 입력을 통한 금융상품 질문
* 금융상품 추천 및 금리 관련 질문 응답
* 투자성향에 따른 금융상품 상담
* 자주 묻는 질문을 활용한 빠른 질문 기능
* ChatGPT 형태의 대화형 UI 구현

### 4. 금융상품 데이터 관리

* CSV 파일 기반 예금상품 데이터 관리
* 금융상품 금리 및 가입조건 데이터 활용
* CSV 컬럼명 정규화 및 데이터 추출
* 파일 경로 자동 탐색 기능
* 금융상품 데이터 로딩 및 추천 로직 구현

## 🚀 실행 방법

### 1. 프로젝트 다운로드

```bash
git clone https://github.com/본인계정/DoriFit.git
```

프로젝트 폴더로 이동합니다.

```bash
cd DoriFit
```

### 2. 가상환경 생성 및 활성화

Windows 기준:

```bash
python -m venv venv
```

```bash
venv\Scripts\activate
```

### 3. 라이브러리 설치

```bash
pip install fastapi uvicorn jinja2 python-multipart python-dotenv openai itsdangerous
```

### 4. 환경변수 설정

프로젝트 최상위 폴더에 `.env` 파일을 생성합니다.

```env
OPENAI_API_KEY=본인의_OpenAI_API_KEY
SESSION_SECRET=임의의_보안용_문자열
```

※ OpenAI API를 사용하는 챗봇 기능은 유효한 API Key가 필요합니다.

### 5. 서버 실행

```bash
python main.py
```

### 6. 웹사이트 접속

브라우저 주소창에 다음 주소를 입력합니다.

```text
http://localhost:5000
```

※ 실제 포트 번호는 `main.py`의 Uvicorn 실행 설정을 기준으로 합니다.

## 💡 프로젝트 핵심 구현 사항

* **개인화 금융서비스:** 회원가입 과정에서 수집한 금융정보를 활용하여 개인별 금융상품 추천 기능 구현
* **데이터 기반 추천:** CSV 형태의 금융상품 데이터를 가공하여 추천 로직에 활용
* **AI 금융상담:** OpenAI API를 연동하여 사용자의 자연어 질문에 대응하는 상담 기능 구현
* **사용자 경험 개선:** 로그인부터 상품 추천, AI 상담까지 하나의 웹 서비스에서 이용할 수 있도록 UI 구성
* **데이터베이스 연동:** SQLite를 활용한 회원정보 저장 및 조회 기능 구현

<br>

## ⚠️ 유의사항

* 금융상품의 금리 및 가입조건은 금융회사 사정에 따라 변경될 수 있습니다.
* 제공되는 금융상품 정보는 참고용이며, 실제 가입 전 금융회사에서 최신 조건을 확인해야 합니다.
* AI 챗봇의 답변은 참고용으로 제공되며, 실제 금융 의사결정을 대신하지 않습니다.
* 개인 API Key 및 비밀번호 등 민감한 정보는 GitHub에 공개하지 않도록 주의해야 합니다.
